# Postern is on pause from September 1 to November 30, 2026

Postern is a one-person project. The maintainer has a hard-deadline family project that lands in late November, and the months leading up to it need full attention.

From September 1 to November 30, 2026, Postern is in maintenance mode:

- Security patches will land.
- Critical bugs that block existing users will get a fix.
- No new features.
- No issue triage on non-critical reports.
- Pull requests will not be reviewed unless they fix a security issue.

Work resumes December 1, 2026. The roadmap picks up at Phase 2.

This pause is on the roadmap on purpose. Building Postern over 20 years means accepting that a few months of slower progress now keeps the rest of the project alive.

Thanks for your patience. The repo stays public during the pause. The discussions stay open. The work resumes when it resumes.

—M
